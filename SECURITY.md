# Security policy

## Supported versions

Kiyosaki does not yet publish versioned releases. Security fixes are applied to
the latest revision of `master` only.

## Reporting a vulnerability

Report suspected vulnerabilities privately through
[GitHub security advisories](https://github.com/zlatanstajic/kiyosaki/security/advisories/new).
Include the affected command or library API, reproduction steps, impact and any
suggested mitigation you have.

Please do not open a public issue for an undisclosed vulnerability. For
non-security bugs and feature requests, use the repository's public issue
tracker.
