# Kiyosaki

**A modern PHP toolkit for lottery history, constrained generation and result
analysis.**

```{toctree}
:maxdepth: 2
:caption: Contents

getting-started
cli
architecture
database

```

Kiyosaki combines SQLite-backed draw history, constrained generation and
result analysis. It is usable as a Composer library or as a command-line
application.

```{warning}
Lottery outcomes are random. Historical frequencies and generated filters are
selection tools, not predictions and not a way to improve mathematical odds.
```
